## 问题
代码中设置的是 "UI" 层，但相机只渲染 "CharacterPreview" 层，导致运行时预览相机拍不到角色。

## 修复
修改 CharacterPreviewPool.cs 第98行：

```csharp
// 修改前
SetLayerRecursively(model, LayerMask.NameToLayer("UI"));

// 修改后  
SetLayerRecursively(model, LayerMask.NameToLayer("CharacterPreview"));
```

## 验证步骤
1. 修改代码
2. 运行游戏
3. 按Q键打开角色选择面板
4. 检查预览相机是否能拍到角色
