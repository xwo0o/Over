## 优化目标

让角色实际移动速度 = 最大速度 × speed参数

## 实现方案

### 修改 CharacterMovementController.cs

1. 添加 `currentSpeedMultiplier` 字段（0-1）
2. 添加公共方法 `SetSpeedMultiplier(float speed)`
3. 在 `UpdateMovement()` 中应用速度乘数：
   ```csharp
   movement *= moveSpeed * currentSpeedMultiplier;
   ```

### 修改 NetworkPlayer.cs

在 `CmdSetSpeed()` 中同步更新 `CharacterMovementController` 的速度乘数：
```csharp
[Command]
public void CmdSetSpeed(float speed)
{
    speed = Mathf.Clamp01(speed);
    syncedSpeed = speed;
    
    // 同步更新移动速度乘数
    if (movementController != null)
    {
        movementController.SetSpeedMultiplier(speed);
    }
}
```

### 优势

1. **动画和移动同步**：speed参数同时控制动画和移动速度
2. **流畅过渡**：speed的平滑过渡会同时影响动画和移动
3. **网络同步**：服务器权威，所有客户端一致
