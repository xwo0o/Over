## 问题根源

在 `EquipResourceVisual` 方法中使用的是 `localSlotIndex`，但 `OnWeaponIdChanged` 和 `OnSlotIndexChanged` 是两个独立的 SyncVar 回调，执行顺序不确定。

当选择非武器资源（木头）时：
1. `OnWeaponIdChanged` 被调用，执行 `EquipResourceVisual()`
2. 但此时 `OnSlotIndexChanged` 可能还没执行，`localSlotIndex` 还是旧值
3. 导致 `EquipResourceVisual` 使用错误的槽位索引

## 修复方案

### 修改 EquipResourceVisual 方法

使用 `currentSlotIndex`（SyncVar）替代 `localSlotIndex`（本地变量），确保使用服务器同步的槽位索引。

**当前代码（错误）：**
```csharp
var slotData = inventory.slots[localSlotIndex];  // 使用本地变量，可能未更新
```

**修复后：**
```csharp
var slotData = inventory.slots[currentSlotIndex];  // 使用SyncVar，确保同步
```
