# 跨世界连接系统 - Unity编辑器设置指南

## 概述

本文档说明如何在Unity编辑器中设置跨世界连接UI面板。

## 已创建的脚本文件

1. **Assets/Scripts/Network/WorldPortalData.cs** - 世界连接数据类
2. **Assets/Scripts/Network/WorldPortalManager.cs** - 世界切换管理器
3. **Assets/Scripts/UI/WorldPortalUI.cs** - UI控制器

## Unity编辑器设置步骤

### 步骤1：创建UI预制体

1. 在Unity编辑器中打开 **GameScene** 场景
2. 在 **Hierarchy** 窗口中右键 → UI → Canvas（如果还没有Canvas）
3. 在Canvas下创建一个新的空GameObject，命名为 **WorldPortalPanel**
4. 设置WorldPortalPanel的Rect Transform：
   - Anchor Presets：按住Alt键点击中心（拉伸全屏）
   - 或者设置为合适的尺寸，例如：Width: 400, Height: 300

### 步骤2：添加UI元素

在 **WorldPortalPanel** 下创建以下UI元素：

#### 2.1 标题文本
- 右键 → UI → Text - TextMeshPro
- 命名为 **TitleText**
- 设置文本内容："跨世界连接"
- 调整字体大小和位置

#### 2.2 IP地址输入框
- 右键 → UI → Input Field - TextMeshPro
- 命名为 **IpInputField**
- Placeholder文本："请输入IP地址 (例如: 127.0.0.1)"
- 调整位置和大小

#### 2.3 端口号输入框
- 右键 → UI → Input Field - TextMeshPro
- 命名为 **PortInputField**
- Placeholder文本："请输入端口号 (例如: 7777)"
- Content Type：选择 Integer Number
- 调整位置和大小

#### 2.4 状态显示文本
- 右键 → UI → Text - TextMeshPro
- 命名为 **StatusText**
- 设置文本内容为空或"准备就绪"
- 调整位置和大小

#### 2.5 连接按钮
- 右键 → UI → Button - TextMeshPro
- 命名为 **ConnectButton**
- 按钮文本："连接"
- 调整位置和大小

#### 2.6 取消按钮
- 右键 → UI → Button - TextMeshPro
- 命名为 **CancelButton**
- 按钮文本："取消"
- 调整位置和大小

### 步骤3：挂载WorldPortalUI脚本

1. 选中 **WorldPortalPanel** GameObject
2. 在 **Inspector** 窗口中点击 **Add Component**
3. 搜索并添加 **WorldPortalUI** 脚本

### 步骤4：关联UI元素引用

在 **WorldPortalUI** 组件的 Inspector 中，将对应的UI元素拖拽到相应的字段：

- **Panel**: 将 **WorldPortalPanel** 自身拖拽到这里
- **Ip Input Field**: 将 **IpInputField** 拖拽到这里
- **Port Input Field**: 将 **PortInputField** 拖拽到这里
- **Connect Button**: 将 **ConnectButton** 拖拽到这里
- **Cancel Button**: 将 **CancelButton** 拖拽到这里
- **Status Text**: 将 **StatusText** 拖拽到这里

### 步骤5：添加打开面板的按钮

1. 在Canvas下创建一个新的Button，命名为 **OpenWorldPortalButton**
2. 按钮文本："传送门"
3. 在Button的 **On Click ()** 事件中：
   - 点击 **+** 号添加事件
   - 将 **WorldPortalPanel** 拖拽到对象槽
   - 在函数下拉菜单中选择 **WorldPortalUI → OpenPanel()**

### 步骤6：（可选）创建预制体

1. 将配置好的 **WorldPortalPanel** 拖拽到 **Project** 窗口的 **Assets/Prefabs/UI/** 文件夹中
2. 删除场景中的WorldPortalPanel（保留预制体引用）
3. 在需要的场景中实例化预制体

## 代码使用示例

### 通过代码打开面板

```csharp
// 打开跨世界连接面板
if (WorldPortalUI.Instance != null)
{
    WorldPortalUI.Instance.OpenPanel();
}
```

### 通过代码切换世界

```csharp
// 直接切换到指定世界
if (WorldPortalManager.Instance != null)
{
    WorldPortalManager.Instance.SwitchWorld("192.168.1.100", 7777);
}
```

### 订阅事件

```csharp
void Start()
{
    if (WorldPortalManager.Instance != null)
    {
        WorldPortalManager.Instance.OnWorldSwitchStarted += OnWorldSwitchStarted;
        WorldPortalManager.Instance.OnWorldSwitchCompleted += OnWorldSwitchCompleted;
        WorldPortalManager.Instance.OnWorldSwitchFailed += OnWorldSwitchFailed;
    }
}

void OnWorldSwitchStarted()
{
    Debug.Log("开始切换世界...");
}

void OnWorldSwitchCompleted()
{
    Debug.Log("世界切换成功！");
}

void OnWorldSwitchFailed(string error)
{
    Debug.LogError($"世界切换失败: {error}");
}

void OnDestroy()
{
    if (WorldPortalManager.Instance != null)
    {
        WorldPortalManager.Instance.OnWorldSwitchStarted -= OnWorldSwitchStarted;
        WorldPortalManager.Instance.OnWorldSwitchCompleted -= OnWorldSwitchCompleted;
        WorldPortalManager.Instance.OnWorldSwitchFailed -= OnWorldSwitchFailed;
    }
}
```

## 注意事项

1. **WorldPortalManager 和 WorldPortalUI 都是单例**，使用 Instance 访问
2. **确保 NetworkConnectionManager 在场景中**，WorldPortalManager 依赖它
3. **目标世界需要运行相同版本的游戏**
4. **首次使用建议先在本地测试**（127.0.0.1）

## 故障排除

### 问题：UI元素引用丢失
- 解决：重新在Inspector中拖拽UI元素到对应字段

### 问题：点击连接没有反应
- 解决：检查控制台日志，查看是否有错误信息
- 解决：确认 NetworkConnectionManager 存在且正常

### 问题：连接失败
- 解决：确认目标世界正在运行
- 解决：检查IP地址和端口号是否正确
- 解决：检查防火墙是否阻止了UDP连接
