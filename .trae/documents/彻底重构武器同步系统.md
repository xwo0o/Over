## 彻底重构方案

### 核心问题
当前系统太复杂，事件订阅、SyncVar、Command 混用，导致同步混乱。

### 彻底重构方案

#### 1. 简化架构
只保留两个组件：
- **PlayerWeaponController** (NetworkBehaviour): 处理输入、网络同步、武器状态
- **WeaponAttachmentSystem** (MonoBehaviour): 处理武器模型挂载（纯表现层）

#### 2. 服务器权威设计
```
客户端输入 → Command → 服务器设置 SyncVar → 所有客户端同步 → 更新表现
```

#### 3. 具体实现

**PlayerWeaponController.cs** (替换 WeaponStateManager + PlayerWeaponInput):
```csharp
public class PlayerWeaponController : NetworkBehaviour
{
    [SyncVar(hook = nameof(OnWeaponChanged))]
    public int currentWeaponId = -1;
    
    // 仅本地玩家处理输入
    void Update() {
        if (!isLocalPlayer) return;
        HandleInput();
    }
    
    // 发送命令到服务器
    [Command]
    void CmdSwitchWeapon(int slotIndex) {
        // 服务器验证并设置武器
        currentWeaponId = GetWeaponIdFromSlot(slotIndex);
    }
    
    // SyncVar 回调 - 所有客户端同步
    void OnWeaponChanged(int oldId, int newId) {
        // 更新武器模型
        attachmentSystem.EquipWeapon(newId);
        // 更新动画
        UpdateAnimator(newId);
    }
}
```

#### 4. 删除多余组件
- 删除 WeaponStateManager
- 删除 PlayerWeaponInput
- 删除 WeaponDamageSystem 中的武器切换逻辑（只保留伤害计算）

#### 5. 统一入口
所有武器相关操作都通过 PlayerWeaponController 处理。
