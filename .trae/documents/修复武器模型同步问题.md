## 问题分析

**根本原因**：
SyncVar 的 hook 回调 `OnWeaponIdChanged` **只在客户端上触发**，不在服务器（主机）上触发。

当前流程：

1. 客户端A调用 `CmdSetWeaponId(weaponId)`
2. 服务器执行 Command，设置 `currentWeaponId = weaponId`
3. SyncVar 同步到所有客户端
4. **问题**：服务器（主机）上不会触发 `OnWeaponIdChanged` 回调
5. 所以主机不会执行 `EquipWeaponInternal`，不会加载武器模型

## 修复方案

### 修改 CmdSetWeaponId 方法

在服务器端手动调用装备逻辑，确保服务器也加载武器模型。

```csharp
[Command]
void CmdSetWeaponId(int weaponId)
{
    Debug.Log($"[WeaponStateManager] CmdSetWeaponId: {weaponId} - 玩家: {netId}");
    
    // 设置SyncVar，会自动触发客户端的OnWeaponIdChanged回调
    currentWeaponId = weaponId;
    
    // 关键修复：服务器也需要执行装备逻辑（因为SyncVar hook不在服务器上触发）
    if (isServer)
    {
        EquipWeaponInternal(weaponId);
    }
    
    // 同时同步到damageSystem
    if (damageSystem != null)
    {
        damageSystem.CmdEquipWeapon(weaponId);
    }
}
```
