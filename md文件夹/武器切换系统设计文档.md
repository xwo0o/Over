# 武器切换系统设计文档

## 1. 系统概述

武器切换系统是《Over》游戏中的核心战斗机制之一，允许玩家在战斗中快速切换不同类型的武器，以适应不同的战斗场景。该系统将与现有的物品栏系统、角色动画系统和网络同步系统深度集成。

## 2. 设计目标

- 支持多种武器类型（近战、远程、特殊武器等）
- 实现流畅的武器切换动画
- 确保网络同步的一致性
- 提供直观的用户输入接口
- 与现有的物品栏系统无缝集成

## 3. 系统架构

### 3.1 核心组件

#### 3.1.1 WeaponSystem.cs
武器系统的核心管理器，负责武器的切换、状态管理和网络同步。

#### 3.1.2 Weapon.cs
武器基类，定义所有武器的共同属性和行为。

#### 3.1.3 WeaponData.json
武器数据配置文件，包含所有武器的属性和配置。

#### 3.1.4 WeaponInputHandler.cs
处理用户输入，将按键映射到武器切换操作。

### 3.2 系统架构图

```
武器切换系统
├── 输入层
│   └── WeaponInputHandler
├── 业务逻辑层
│   ├── WeaponSystem
│   └── Weapon（基类）
├── 数据层
│   ├── WeaponData.json
│   └── Inventory（现有系统）
├── 表现层
│   ├── 武器模型
│   └── 动画系统
└── 网络层
    └── 网络同步（Mirror）
```

### 4.3 武器切换流程

```
武器切换流程
1. 用户按下武器切换按键
2. WeaponInputHandler捕获输入
3. WeaponSystem验证切换请求
4. 检查物品栏中是否有目标武器
5. 播放武器切换动画
6. 同步武器状态到所有客户端
7. 更新当前武器属性
8. 显示武器UI
```

## 5. 网络同步设计

### 5.1 同步策略

- 使用SyncVar同步当前武器ID
- 使用Command处理客户端到服务器的武器切换请求
- 使用ClientRpc广播武器切换状态

### 5.2 核心代码示例

```csharp
[SyncVar(hook = nameof(OnCurrentWeaponChanged))]
private string currentWeaponId;

[Command(requiresAuthority = true)]
public void CmdSwitchWeapon(string weaponId)
{
    // 服务器验证武器切换请求
    if (inventory.HasItem(weaponId))
    {
        currentWeaponId = weaponId;
        RpcSwitchWeapon(weaponId);
    }
}

[ClientRpc]
private void RpcSwitchWeapon(string weaponId)
{
    // 客户端执行武器切换
    SwitchWeapon(weaponId);
}
```

## 6. 武器实例位置指定

### 6.1 骨骼绑定方式

武器实例将通过骨骼绑定的方式附加到角色模型上。推荐的绑定位置：

#### 6.1.1 手持武器
- 主手：`Bip001 R Hand` 或 `RightHand`
- 副手：`Bip001 L Hand` 或 `LeftHand`

#### 6.1.2 背挂武器
- 背部：`Bip001 Spine2` 或 `Spine3`
- 腰部：`Bip001 Pelvis` 或 `Hips`

### 6.2 位置调整

```csharp
// 武器位置偏移
public Vector3 weaponPositionOffset = new Vector3(0.1f, -0.05f, 0.2f);
// 武器旋转偏移
public Vector3 weaponRotationOffset = new Vector3(-30f, 0f, 0f);
```

### 6.3 实现代码

```csharp
public void AttachWeaponToBone(GameObject weaponObject, string boneName)
{
    Transform boneTransform = characterModel.transform.Find(boneName);
    if (boneTransform != null)
    {
        weaponObject.transform.SetParent(boneTransform);
        weaponObject.transform.localPosition = weaponPositionOffset;
        weaponObject.transform.localRotation = Quaternion.Euler(weaponRotationOffset);
        weaponObject.transform.localScale = Vector3.one;
    }
}
```
