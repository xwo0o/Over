# 武器系统脚本挂载指南

## 概述

武器系统包含以下核心组件，需要正确挂载到Player预制体上才能正常工作。

---

## Player预制体结构

```
Player (根节点)
├── ModelParent (模型父节点)
│   └── 角色模型 (包含Animator)
├── 武器系统组件
├── 移动系统组件
└── 其他组件
```

---

## 必需组件挂载

### 1. WeaponDatabase (武器数据库)

| 项目 | 说明 |
|------|------|
| **挂载位置** | 场景中的任意GameObject（建议挂在GameManager或单独创建） |
| **组件** | `WeaponDatabase.cs` |
| **配置** | 无需配置，自动从 `StreamingAssets/WeaponData.json` 加载 |
| **数量** | 整个场景只需1个 |

**说明**：单例模式，所有武器数据从这里读取。

---

### 2. WeaponAttachmentSystem (武器挂载系统)

| 项目 | 说明 |
|------|------|
| **挂载位置** | Player预制体**根节点** |
| **组件** | `WeaponAttachmentSystem.cs` |

**Inspector配置：**

```csharp
[Header("骨骼设置")]
SceneAwareAnimatorManager animatorManager    // 自动查找或手动拖拽
Animator characterAnimator                   // 可选，自动查找

[Header("偏移设置")]
Vector3 rightHandPositionOffset = Vector3.zero    // 右手武器位置偏移
Vector3 rightHandRotationOffset = Vector3.zero    // 右手武器旋转偏移
Vector3 leftHandPositionOffset = Vector3.zero     // 左手武器位置偏移
Vector3 leftHandRotationOffset = Vector3.zero     // 左手武器旋转偏移
Vector3 weaponScale = Vector3.one                 // 武器缩放

[Header("可选设置")]
bool playSwitchSound = true                  // 是否播放切换音效
AudioClip switchSound                        // 切换音效剪辑
```

**说明**：负责将武器模型挂载到角色骨骼上（Prop_R/Prop_L）。

---

### 3. WeaponDamageSystem (武器伤害系统)

| 项目 | 说明 |
|------|------|
| **挂载位置** | Player预制体**根节点** |
| **组件** | `WeaponDamageSystem.cs` |

**Inspector配置：**

```csharp
[Header("基础设置")]
int currentWeaponId = -1                     // 当前武器ID（运行时自动设置）

[Header("攻击判定")]
LayerMask attackLayerMask                    // 攻击检测层级（选择Enemy等）
Vector3 attackOriginOffset = Vector3.zero    // 攻击检测原点偏移

[Header("连击系统")]
int currentComboStage = 0                    // 当前连击阶段（运行时自动）
bool isInComboWindow = false                 // 是否在连击窗口（运行时自动）
float comboResetTime = 1.5f                  // 连击重置时间
```

**说明**：处理伤害计算、连击系统、攻击判定。

---

### 4. WeaponStateManager (武器状态管理器)

| 项目 | 说明 |
|------|------|
| **挂载位置** | Player预制体**根节点** |
| **组件** | `WeaponStateSystem.cs` |

**Inspector配置：**

```csharp
[Header("系统引用")]
WeaponAttachmentSystem attachmentSystem      // 自动查找或手动拖拽
WeaponDamageSystem damageSystem              // 自动查找或手动拖拽
SceneAwareAnimatorManager animatorManager    // 自动查找或手动拖拽

[Header("攻击设置")]
KeyCode attackKey = Mouse0                   // 攻击键（默认鼠标左键）
float attackRadius = 1.5f                    // 攻击检测半径
float attackDistance = 2.0f                  // 攻击检测距离
LayerMask attackLayerMask                    // 攻击检测层级
```

**说明**：主控制器，整合所有武器系统，处理输入和动画。

---

### 5. WeaponAnimEvents (武器动画事件接收器)

| 项目 | 说明 |
|------|------|
| **挂载位置** | **模型根节点**（Animator所在的GameObject） |
| **组件** | `WeaponAnimEvents.cs` |

**Inspector配置：**

```csharp
[Header("系统引用")]
WeaponStateManager weaponStateManager        // 自动查找或手动拖拽
WeaponDamageSystem damageSystem              // 自动查找或手动拖拽
Animator animator                            // 自动查找或手动拖拽
```

**重要**：这个组件必须挂在**有Animator的GameObject**上，因为动画事件只能由Animator所在物体接收。

## 组件依赖关系

```
WeaponStateManager (主控制器)
    ├── WeaponAttachmentSystem (挂载武器)
    ├── WeaponDamageSystem (伤害计算)
    └── SceneAwareAnimatorManager (动画控制)

WeaponAnimEvents (动画事件)
    ├── WeaponStateManager
    ├── WeaponDamageSystem
    └── Animator

PreviewWeaponController (预览)
    ├── InventoryUIController
    └── WeaponAttachmentSystem
```

## 常见问题

### Q1: 动画事件不触发？
**检查**：`WeaponAnimEvents` 是否挂在**Animator所在的GameObject**上。

### Q2: 武器不显示？
**检查**：`WeaponAttachmentSystem` 的 `animatorManager` 是否正确引用。

### Q3: 伤害不生效？
**检查**：
1. `attackLayerMask` 是否包含目标层级
2. 目标是否有 `IDamageable` 接口实现
3. 是否在服务器端运行

### Q4: 连击不工作？
**检查**：
1. 动画事件 `AE_OpenWindow` 和 `AE_CloseWindow` 是否正确配置
2. `WeaponDamageSystem` 的 `comboResetTime` 是否合理

---

## 快速配置步骤

1. **场景配置**：创建空物体，挂载 `WeaponDatabase`
2. **Player根节点**：依次挂载 `WeaponAttachmentSystem`、`WeaponDamageSystem`、`WeaponStateManager`
3. **模型节点**：挂载 `WeaponAnimEvents`
4. **配置引用**：在Inspector中配置各组件的引用（或勾选autoFindComponents自动查找）
5. **配置层级**：设置 `attackLayerMask` 为包含敌人的层级
6. **测试运行**：进入游戏测试武器切换和攻击
